# -Chess-World-Offline-Edition-
This game is offline avaliable! (you must first downlaod it)

Hey folks! 👋 Yep, this is my third crack at making a game — I'm slowly figuring out this whole coding thing, promise.

‌
Chess World (Offline Edition)‌ is a cozy, zero-dependency collection of classic board games, built entirely with vanilla JavaScript and Canvas. No servers,  no annoying ads — 
just copy the web adress https://horzionexpress.github.io/-Chess-World-Offline-Edition-/ and you're ready to play, even on a plane with no Wi-Fi. ♟️✨(you need to downlaod it first to play offline!)

How to play?

Pick your favorite game from the menu, pick an AI difficulty (easy for lazy afternoons, hard for when you wanna get humbled), and tap pieces to move. Pause anytime, close the tab, and your match will be right where you left it when you come back.

What's packed in

8+ classic board games all in one single file

3 AI difficulty levels for casual and tryhard players alike

Full offline PWA support, installable to your home screen

Auto-save & one-click resume for unfinished matches

Detailed match history tracking wins, losses and playtime

Tiered achievement system with 6 rarity levels of collectible badges

Eye-friendly dark theme with animated starry background

Full mobile touch support, plus big font & power-saving modes

Zero external assets — every sound, icon and logic is built right in

I swear there are fewer spaghetti code bits than my last two projects, but if you spot wonky AI moves or janky UI, open an issue! New game suggestions and PRs are always welcome. Go play a round! 🎲
